# Reembolso de Consultas - Test Doubles em Java

Projeto criado para praticar testes unitários em Java utilizando diferentes tipos de dublês de teste.

## Conceitos aplicados

- Dummy: objeto usado apenas para preencher um parâmetro.
- Fake: implementação simples em memória, sem banco de dados.
- Stub: objeto que retorna valores fixos para o teste.
- Spy: objeto que registra se determinado método foi chamado.
- Mock: objeto simulado com Mockito para controlar comportamentos.
- Helper: método auxiliar para evitar repetição na criação de objetos.

## Contexto do projeto

O projeto simula um sistema de cálculo de reembolso de consultas médicas.

A cada exercício, uma nova técnica de teste é aplicada ao mesmo contexto.
